# Plintora
#### Um aplicativo de anotação simples, 
#### Configuração do aplicativo
#### nesse aplicativo contém uma tela de login, depois de fazer login, irá abrir um menu com três opções, adicionar, listar e sair.

### Como iniciar o aplicativo
#### 1- clonar o repositorio
<h6> 2- git clone https://github.com/BLAKAUT666/Plintora.git</h6>
<h6> 3- abra o terminal ou vscode</h6>
<h6> 4- javac -d bin dominio/Config/*.java services/*.java teste/*.java</h6>
<h6> 5- java -cp bin teste/testeApp</h6>
